# Εργαλεία ενημέρωσης του FM-DX Webserver

*(In English: [README.md](README.md))*

Εργαλεία ενημέρωσης με ένα κλικ που φέρνουν το **ίδιο το FM-DX Webserver** στην τελευταία έκδοση **χωρίς να χάσετε τις ρυθμίσεις ή τα πρόσθετά σας**.

Και τα δύο σκριπτ:
- βρίσκουν μόνα τους τον φάκελο `fm-dx-webserver` (ή δίνετε εσείς τη διαδρομή),
- κρατούν πρώτα **αντίγραφο ασφαλείας** των ρυθμίσεων και των πρόσθετων,
- ενημερώνουν στην τελευταία έκδοση και τρέχουν `npm install`,
- **σταματούν χωρίς να αλλάξουν τίποτα** αν κάτι δεν είναι σωστό.

Κρατούν το `config.json`, όλα τα πρόσθετα, τις ρυθμίσεις τους, τις συνδέσεις και το session secret (το FM-DX τα αγνοεί στο git, οπότε ένα `git pull` δεν τα πειράζει ποτέ). Κρατούν επίσης τις γραμμές των πρόσθετων στα `server/chat.js` / `server/index.js`· αν ποτέ χαθούν, ανοίξτε το **Setup** και πατήστε **🔧 Fix it now** σε κάθε πρόσθετο.

---

## Windows — βήμα βήμα

Χρησιμοποιεί το [`update-fm-dx-windows.bat`](update-fm-dx-windows.bat).

1. **Σταματήστε το FM-DX Webserver** — κλείστε το παράθυρό του (το μαύρο παράθυρο), για να μην είναι κλειδωμένα τα αρχεία.
2. **Κατεβάστε το εργαλείο.** Πατήστε το **πλήκτρο Windows**, γράψτε **cmd**, πατήστε **Enter** και επικολλήστε αυτή τη γραμμή:
   ```
   curl -L -o "%USERPROFILE%\Downloads\update-fm-dx-windows.bat" https://raw.githubusercontent.com/konsvlac1/fmdx-plugins/main/updater/update-fm-dx-windows.bat
   ```
   (Αποθηκεύεται στον φάκελο **Downloads**. Μπορείτε επίσης να το κατεβάσετε από τη σελίδα στο GitHub.)
3. **Τρέξτε το.** Ανοίξτε τον φάκελο **Downloads** και κάντε **διπλό κλικ** στο `update-fm-dx-windows.bat`.
   *(Συμβουλή: τρέξτε το από το παράθυρο `cmd` με `"%USERPROFILE%\Downloads\update-fm-dx-windows.bat"` για να διαβάζετε όλα τα μηνύματα.)*
4. **Επιβεβαιώστε τον φάκελο.** Δείχνει τον φάκελο `fm-dx-webserver` που βρήκε και ρωτάει `Update THIS folder? [Y/N]`. Πατήστε **Y** και **Enter**.
   *(Αν δεν τον βρει, κλείστε το και τρέξτε πρώτα: `set FMDX_DIR=C:\path\to\fm-dx-webserver`, μετά ξανατρέξτε το `.bat`.)*
5. **Περιμένετε.** Κρατάει αντίγραφο ασφαλείας, κατεβάζει την τελευταία έκδοση και τρέχει `npm install`. Όταν πει **Done.**, κλείστε το παράθυρο.
6. **Ξεκινήστε ξανά το FM-DX Webserver.**

## Linux / Raspberry Pi — βήμα βήμα

Χρησιμοποιεί το [`update-fm-dx-linux.sh`](update-fm-dx-linux.sh).

1. **Σταματήστε το FM-DX Webserver** για να μη χρησιμοποιούνται τα αρχεία:
   ```
   sudo systemctl stop fm-dx-webserver     # ή κλείστε το παράθυρο / Ctrl+C εκεί που τρέχει
   ```
2. **Κατεβάστε το εργαλείο:**
   ```
   curl -LO https://raw.githubusercontent.com/konsvlac1/fmdx-plugins/main/updater/update-fm-dx-linux.sh
   ```
3. **Κάντε το εκτελέσιμο:**
   ```
   chmod +x update-fm-dx-linux.sh
   ```
4. **Τρέξτε το:**
   ```
   ./update-fm-dx-linux.sh
   ```
   *(Αν δεν βρει τον φάκελο, δώστε τον: `./update-fm-dx-linux.sh /home/pi/fm-dx-webserver`. Για καθόλου ερωτήσεις, προσθέστε `-y`.)*
5. **Επιβεβαιώστε.** Δείχνει τον φάκελο `fm-dx-webserver` που βρήκε και ρωτάει αν να τον ενημερώσει — απαντήστε **y**. Μετά κρατάει αντίγραφο ασφαλείας, ενημερώνει στην τελευταία έκδοση και τρέχει `npm install`.
6. **Ξεκινήστε ξανά το FM-DX.** Αν υπάρχει service `fm-dx-webserver` στο systemd, το σκριπτ προτείνει να το κάνει επανεκκίνηση· αλλιώς ξεκινήστε το όπως συνήθως.

---

Αν κάποια φορά πει ότι χάθηκαν οι γραμμές των πρόσθετων, ανοίξτε το **Setup** στο FM-DX και πατήστε **🔧 Fix it now** σε κάθε πρόσθετο, μετά κάντε επανεκκίνηση.
