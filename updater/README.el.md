# Εργαλεία ενημέρωσης του FM-DX Webserver

*(In English: [README.md](README.md))*

Ενημερώστε το **FM-DX Webserver** στην τελευταία έκδοση με **μία εντολή**. Κρατάει όλες τις ρυθμίσεις και τα πρόσθετά σας, και κάνει τα υπόλοιπα μόνο του:

> σταματάει τον server → κρατάει αντίγραφο ασφαλείας ρυθμίσεων και πρόσθετων → βρίσκει τον φάκελο → ενημερώνει στην τελευταία έκδοση → `npm ci` → ξεκινάει ξανά τον server.

Εσείς πατάτε μόνο **Y** μία φορά για να επιβεβαιώσετε τον φάκελο. Αν κάτι δεν είναι σωστό, σταματάει χωρίς να αλλάξει τίποτα.

---

## Windows

Πατήστε το **πλήκτρο Windows**, γράψτε **cmd**, πατήστε **Enter** και επικολλήστε αυτή τη **μία γραμμή**:

```
curl -Ls -o "%TEMP%\fmdx-update.bat" https://raw.githubusercontent.com/konsvlac1/fmdx-plugins/main/updater/update-fm-dx-windows.el.bat && "%TEMP%\fmdx-update.bat"
```

Αυτό ήταν. (Αν δεν βρει τον φάκελο, τρέξτε πρώτα `set FMDX_DIR=C:\path\to\fm-dx-webserver` και μετά ξαναεπικολλήστε τη γραμμή.)

## Linux / Raspberry Pi

Επικολλήστε αυτή τη **μία γραμμή** σε ένα terminal:

```
curl -Ls https://raw.githubusercontent.com/konsvlac1/fmdx-plugins/main/updater/update-fm-dx-linux.el.sh | bash
```

Για συγκεκριμένο φάκελο, ή για να παραλείψετε όλες τις ερωτήσεις, προσθέστε ορίσματα:

```
curl -Ls https://raw.githubusercontent.com/konsvlac1/fmdx-plugins/main/updater/update-fm-dx-linux.el.sh | bash -s -- -y /home/pi/fm-dx-webserver
```

### Τι κρατάει

Το `config.json`, όλα τα πρόσθετα, τις ρυθμίσεις τους, τις συνδέσεις και το session secret — το FM-DX τα αγνοεί στο git, οπότε η ενημέρωση δεν τα πειράζει ποτέ. Φτιάχνεται επίσης ένας φάκελος αντιγράφου ασφαλείας με ημερομηνία, για κάθε ενδεχόμενο.

**Οι δικές σας αλλαγές προστατεύονται.** Αν αλλάξατε εσείς κάποιο βασικό αρχείο (θέμα, κάποια τροποποίηση, τις γραμμές των πρόσθετων), το εργαλείο τις εντοπίζει και κρατάει αντίγραφο στο backup — στο `custom/` (αρχεία που αλλάξατε, σε git εγκαταστάσεις) ή στο `replaced/` (όποιο βασικό αρχείο αντικατασταθεί σε ενημέρωση με ZIP) — ώστε η ενημέρωση να μην μπορεί ποτέ να σβήσει σιωπηλά κάτι που προσαρμόσατε.

Αν κάποια φορά πει ότι χάθηκαν οι γραμμές των πρόσθετων, ανοίξτε το **Setup** στο FM-DX και πατήστε **🔧 Fix it now** σε κάθε πρόσθετο.
