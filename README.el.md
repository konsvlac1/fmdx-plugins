# Πρόσθετα (plugins) για το FM-DX Webserver

🇬🇧 [English](README.md)

Έξι δωρεάν πρόσθετα που βοηθούν όποιον έχει δημόσιο δέκτη FM-DX:

| Πρόσθετο | Τι κάνει για εσάς |
|---|---|
| 📒 **Station Log** | Καταγράφει αυτόματα κάθε σταθμό που πιάνει ο δέκτης σας: συχνότητα, PI, όνομα, περιοχή, καλύτερο σήμα, πρώτη και τελευταία φορά. Έτσι έχετε μια λίστα «τι πιάνεται εδώ», με αναζήτηση και λήψη σε Excel. Μπορείτε να τη δείξετε και στους ακροατές σας. |
| 📊 **Listener Insights** | Δείχνει πώς χρησιμοποιείται ο server σας: επισκέπτες ανά ημέρα, ώρες και ημέρες αιχμής, οι πιο δημοφιλείς σταθμοί, χώρες και πόση ώρα μένει ο κόσμος. Προαιρετικά, εβδομαδιαία σύνοψη στο Telegram. Δεν αποθηκεύει διευθύνσεις IP. |
| 🎧 **Fair Tuner Sharing** | Όταν είναι συνδεδεμένοι πολλοί ακροατές, όποιος αλλάζει συχνότητα παίρνει μια σύντομη «σειρά» (2 λεπτά μετά την τελευταία αλλαγή, το πολύ 10 λεπτά). Οι υπόλοιποι βλέπουν μια φιλική αντίστροφη μέτρηση, αντί η συχνότητα να αλλάζει συνέχεια. Εσείς (ο διαχειριστής) αλλάζετε πάντα συχνότητα. |
| 🛡️ **Chat Filter** | Ελέγχει κάθε μήνυμα του chat **πριν το δει κανείς**. Μηνύματα με προσβλητικές λέξεις ή φράσεις (ελληνικά, greeklish, αγγλικά, με όποιον τρόπο κι αν γραφτούν) δεν στέλνονται, και μόνο ο αποστολέας βλέπει ένα σύντομο μήνυμα. Σταματά επίσης τους **διαφημιστικούς συνδέσμους** και το ίδιο μήνυμα όταν στέλνεται ξανά και ξανά. Όποιος επιμένει, μπαίνει σε σίγαση για λίγο. Οι κανονικές λέξεις δεν επηρεάζονται. |
| 🛰️ **Antenna Advisor** | Για δέκτες με **δύο ή περισσότερες κεραίες**: τις συγκρίνει στη συχνότητα που ακούτε και σας λέει ποια πιάνει καλύτερα (σήμα, RDS, στέρεο). Αλλάζει για λίγο κάθε κεραία, μετράει και μετά επαναφέρει τη δική σας. Μπορείτε επίσης να τρέξετε **σάρωση όλης της μπάντας** που συγκρίνει τις κεραίες σε κάθε σταθμό με σήμα και φτιάχνει έναν χάρτη «καλύτερη κεραία ανά συχνότητα», καθώς και να **διαγράψετε** αποθηκευμένες συγκρίσεις (μία ή όλες). Οι επαναλαμβανόμενες δοκιμές κρατούν έναν μικρό μετρητή (π.χ. *κέρδισε 7/8*) ώστε να βλέπετε αν ο νικητής είναι σταθερός. Μόνο εσείς (ο διαχειριστής) ξεκινάτε σύγκριση ή σάρωση· οι ακροατές βλέπουν απλώς ποια κεραία προτείνεται. Σε δέκτη με μία κεραία παραμένει κρυφό. |
| 📻 **DX Watch** | Παρακολουθεί ό,τι αποκωδικοποιεί **ο δικός σας δέκτης** και σας ειδοποιεί όταν πιαστεί σταθμός που σας ενδιαφέρει — ένας κωδικός **PI**, μια **συχνότητα**, ή **οποιοσδήποτε νέος σταθμός** που δεν έχετε ξαναπιάσει. Οι ειδοποιήσεις εμφανίζονται στη σελίδα και μπορούν να πάνε σε **Discord** και **Telegram**, με μικρή καθυστέρηση ώστε να μην επαναλαμβάνεται το ίδιο. Δεν αλλάζει ποτέ τον δέκτη. |

Κάθε πρόσθετο έχει τη δική του καρτέλα στη σελίδα **Setup** (ρυθμίσεις διαχειριστή).

## Εγκατάσταση

Χρειάζεστε **FM-DX Webserver 1.4** και περίπου 5 λεπτά.

### Raspberry Pi / Linux

1. Ανοίξτε ένα **τερματικό** (Terminal).
2. Αντιγράψτε και επικολλήστε τις παρακάτω γραμμές. Αλλάξτε το `/home/pi/fm-dx-webserver` με τον φάκελο όπου είναι το δικό σας FM-DX.
```
cd ~
wget -O konvlachos-plugins.zip https://github.com/konsvlac1/fmdx-plugins/archive/refs/heads/main.zip && unzip -o konvlachos-plugins.zip
sudo node fmdx-plugins-main/install.js /home/pi/fm-dx-webserver
```
3. Αν σας ζητήσει κωδικό, γράψτε τον κωδικό του Raspberry Pi και πατήστε **Enter** (δεν φαίνεται όσο γράφετε, είναι φυσιολογικό).

### Windows

1. Κατεβάστε το αρχείο: https://github.com/konsvlac1/fmdx-plugins/archive/refs/heads/main.zip
2. Στις **Λήψεις** (Downloads), κάντε δεξί κλικ στο αρχείο ZIP → **Εξαγωγή όλων…** → **Εξαγωγή**.
3. Πατήστε το **πλήκτρο Windows**, γράψτε **cmd** και πατήστε **Enter**.
4. Στο μαύρο παράθυρο, γράψτε την παρακάτω γραμμή (αλλάξτε το `C:\fm-dx-webserver` με τον φάκελο του δικού σας FM-DX) και πατήστε **Enter**:
```
node "%USERPROFILE%\Downloads\fmdx-plugins-main\fmdx-plugins-main\install.js" "C:\fm-dx-webserver"
```

### Μετά (για όλους)

1. Ανοίξτε τη σελίδα του FM-DX σας, συνδεθείτε ως **διαχειριστής** (admin) και πηγαίνετε **Setup → Plugins**.
2. Τσεκάρετε **Station Log**, **Listener Insights**, **Fair Tuner Sharing**, **Chat Filter**, **Antenna Advisor** και **DX Watch** και πατήστε **Save**.
3. Κάντε **επανεκκίνηση** (restart) του FM-DX Webserver.
4. Στο **Setup** εμφανίζονται πλέον οι καρτέλες **Station Log**, **Listener Insights**, **Fair Tuner Sharing**, **Chat Filter**, **Antenna Advisor** και **DX Watch**. (Το Antenna Advisor εμφανίζεται μόνο σε δέκτες με δύο ή περισσότερες κεραίες.)

### Μόνο ένα πρόσθετο

Κάντε τα ίδια βήματα όπως παραπάνω, αλλά γράψτε το **όνομα** του πρόσθετου στο **τέλος** της γραμμής εγκατάστασης.
Διαλέξτε το όνομα από αυτόν τον πίνακα:

| Πρόσθετο | Όνομα που γράφετε |
|---|---|
| 📒 Station Log | `StationLog` |
| 📊 Listener Insights | `ListenerInsights` |
| 🎧 Fair Tuner Sharing | `FairShare` |
| 🛡️ Chat Filter | `ChatFilter` |
| 🛰️ Antenna Advisor | `AntennaAdvisor` |
| 📻 DX Watch | `DXWatch` |

Παράδειγμα με το Chat Filter (για άλλο πρόσθετο, γράψτε αντί γι' αυτό άλλο όνομα από τον πίνακα):

**Windows** (στο μαύρο παράθυρο `cmd`):
```
node "%USERPROFILE%\Downloads\fmdx-plugins-main\fmdx-plugins-main\install.js" "C:\fm-dx-webserver" ChatFilter
```

**Raspberry Pi / Linux:**
```
sudo node fmdx-plugins-main/install.js /home/pi/fm-dx-webserver ChatFilter
```

Μετά, στο **Setup → Plugins** τσεκάρετε μόνο αυτό το πρόσθετο, πατήστε **Save** και κάντε επανεκκίνηση του FM-DX.
Για δύο ή περισσότερα, γράψτε τα ονόματα με κενό ανάμεσα (π.χ. `StationLog ChatFilter`).

*Το Scan Guard είναι ξεχωριστή λήψη: δείτε το [fmdx-scan-guard](https://github.com/konsvlac1/fmdx-scan-guard/blob/main/README.el.md).*

**Απεγκατάσταση:** τρέξτε την ίδια γραμμή εγκατάστασης με ` --uninstall` στο τέλος και κάντε επανεκκίνηση του FM-DX.

### Ενημέρωση του FM-DX (Linux ή Windows)

Ενημερώστε το FM-DX Webserver στην τελευταία έκδοση με **μία εντολή** — σταματάει τον server, κρατάει αντίγραφο ασφαλείας ρυθμίσεων και πρόσθετων, ενημερώνει, τρέχει `npm install` και ξεκινάει ξανά τον server, **χωρίς να χάσετε τις ρυθμίσεις ή τα πρόσθετά σας**. Εσείς πατάτε μόνο **Y** μία φορά για τον φάκελο. Αναλυτικά: [`updater/`](updater/).

**Windows** — σε παράθυρο `cmd`:
```
curl -Ls -o "%TEMP%\fmdx-update.bat" https://raw.githubusercontent.com/konsvlac1/fmdx-plugins/main/updater/update-fm-dx-windows.el.bat && "%TEMP%\fmdx-update.bat"
```

**Linux / Raspberry Pi** — σε ένα terminal:
```
curl -Ls https://raw.githubusercontent.com/konsvlac1/fmdx-plugins/main/updater/update-fm-dx-linux.el.sh | bash
```

Κρατάει το `config.json`, όλα τα πρόσθετα, τις ρυθμίσεις τους και τις συνδέσεις. Αν σας πει ότι χάθηκαν οι γραμμές των πρόσθετων, ανοίξτε το **Setup** και πατήστε **🔧 Fix it now** σε κάθε πρόσθετο.

## 🛡️ Chat Filter: πώς το χρησιμοποιείτε

Ανοίξτε **Setup → Chat Filter**. Από εκεί τα ρυθμίζετε όλα με ένα κλικ:

**Βασικά**
- **✅ On / Off**: ενεργοποιεί ή απενεργοποιεί το φίλτρο.
- **Όταν ένα μήνυμα έχει προσβλητική λέξη**:
  - **🚫 Don't send it**: το μήνυμα δεν στέλνεται (προτείνεται).
  - **✳️ Send it with \*\*\***: το μήνυμα στέλνεται, αλλά η λέξη γίνεται `***`.

**Επιπλέον επιλογές (Also)**
- **Stop the same message sent again (5 min)**: το ίδιο μήνυμα δεν μπορεί να σταλεί ξανά μέσα σε 5 λεπτά (για όσους «τρολάρουν»).
- **Block links (spam)**: δεν επιτρέπονται σύνδεσμοι (links), εκτός από τις **επιτρεπόμενες σελίδες** και τη δική σας σελίδα.
- **Admins too (bad words)**: το φίλτρο ισχύει και για τους διαχειριστές (μόνο για τις προσβλητικές λέξεις).
- **Check nicknames too**: ελέγχει και τα ψευδώνυμα.

**Σίγαση (Mute)**
- Επιλέξτε μετά από πόσα μηνύματα που σταμάτησαν μπαίνει κάποιος σε σίγαση (2, 3 ή 5, ή ποτέ) και για πόσο (10 λεπτά, 1 ώρα, 1 ημέρα).

**Λέξεις που μπλοκάρονται (Blocked words)**
- Γράψτε μια λέξη ή φράση στο κουτί **add a word or phrase** και πατήστε **➕ Add** (ή Enter).
- Μια λέξη που τελειώνει σε `*` μπλοκάρει και όσες λέξεις αρχίζουν έτσι (π.χ. `troll*`).
- Οι ελληνικές λέξεις πιάνουν αυτόματα και τα greeklish, τα κεφαλαία και τις λέξεις χωρίς τόνους.
- Τις δικές σας λέξεις τις αφαιρείτε με το **✕**. Οι **🔒 ενσωματωμένες λέξεις** (εκατοντάδες, ελληνικά και αγγλικά) μένουν πάντα ενεργές.
- Οι ενσωματωμένες λέξεις εμφανίζονται ως `****`. Πατήστε **👁 Show words** για να τις δείτε και **🙈 Hide words** για να τις κρύψετε ξανά.

**Επιτρεπόμενες σελίδες (Allowed sites)**
- Σύνδεσμοι προς αυτές τις σελίδες επιτρέπονται (π.χ. `fmdx.org`). Μια σελίδα επιτρέπει και τις υποσελίδες της (`fmdx.org` → `maps.fmdx.org`).
- Προσθέτετε με **➕ Add** και αφαιρείτε με **✕**.

**Δοκιμή (Try a message)**
- Γράψτε ένα μήνυμα και πατήστε **Test**: θα δείτε αν θα σταλεί ή θα σταματήσει, χωρίς να το δει κανείς στο chat.

**Μηνύματα που σταμάτησαν (Stopped messages)**
- Δείχνει ποιος έστειλε τι, πότε και γιατί σταμάτησε. Οι προσβλητικές λέξεις εμφανίζονται ως `****` μέχρι να πατήσετε **👁 Show messages**.
- Με **🔇 Mute 1 day** βάζετε κάποιον σε σίγαση για μία ημέρα. Στο **Muted now** τον βγάζετε από τη σίγαση με **Unmute**.
- Με **Clear the list** καθαρίζει η λίστα.

**Τι βλέπει ο αποστολέας**
- Μόνο εκείνος βλέπει ένα σύντομο μήνυμα από το **🛡️ Chat Filter** (π.χ. ότι το μήνυμα δεν στάλθηκε), και το κείμενό του επιστρέφει στο κουτί του chat για να το διορθώσει. Οι υπόλοιποι δεν βλέπουν τίποτα.

## Συχνές ερωτήσεις

**Τα πρόσθετα κάνουν πιο αργό τον server;**
Όχι. Το Station Log και το DX Watch κοιτάζουν τον δέκτη μία φορά το δευτερόλεπτο, το Listener Insights κάθε 10 δευτερόλεπτα και το Chat Filter δουλεύει μόνο όταν κάποιος στέλνει μήνυμα στο chat. Το Antenna Advisor δεν κάνει τίποτα μέχρι να πατήσετε το κουμπί του. Αποθηκεύουν μόνο ένα μικρό αρχείο κάθε τόσο.

**Τι αλλάζει το Antenna Advisor στο FM-DX;**
Τίποτα μόνιμο. Όταν πατήσετε **Compare now**, αλλάζει την κεραία για λίγα δευτερόλεπτα για να μετρήσει την καθεμία και μετά επαναφέρει τη δική σας. Δεν χρειάζεται επιπλέον γραμμή στο FM-DX. Εμφανίζεται μόνο σε δέκτες με δύο ή περισσότερες κεραίες, και μόνο ο διαχειριστής ξεκινά τη σύγκριση (ο ήχος τρεμοπαίζει για λίγο όσο αλλάζει κεραία).

**Πώς παίρνω ειδοποιήσεις DX Watch σε Discord ή Telegram;**
Στην καρτέλα DX Watch, επικολλήστε ένα **webhook URL** του Discord (στο Discord: Server Settings → Integrations → Webhooks → New Webhook → Copy URL). Για Telegram χρησιμοποιεί το ίδιο αρχείο `.fmdx-telegram` με το Listener Insights, ή γράφετε bot token και chat id στην καρτέλα. Πατήστε **Send a test alert** για δοκιμή. Προσθέτετε στόχους (PI, συχνότητα, ή «οποιοσδήποτε νέος σταθμός») στην ίδια καρτέλα.

**Τι αλλάζει στο ίδιο το FM-DX;**
Τα πρόσθετα του FM-DX δεν μπορούν μόνα τους να σταματήσουν αλλαγές συχνότητας ή μηνύματα του chat. Γι' αυτό ο εγκαταστάτης προσθέτει μία γραμμή στο `server/index.js` (για το Fair Tuner Sharing) και μία στο `server/chat.js` (για το Chat Filter), και κρατά αντίγραφο ασφαλείας. Η απεγκατάσταση τις αφαιρεί ακριβώς.

**Μια καρτέλα γράφει «One more step is needed»;** (Chat Filter ή Fair Tuner Sharing)
Το πρόσθετο αντιγράφηκε με το χέρι στον φάκελο `plugins`, οπότε λείπει η γραμμή που χρειάζεται στο ίδιο το FM-DX.
Πατήστε **🔧 Fix it now** σε αυτό το μήνυμα και κάντε επανεκκίνηση του FM-DX. (Το ίδιο κάνει και η γραμμή εγκατάστασης.)
Το Station Log και το Listener Insights δεν χρειάζονται τίποτα επιπλέον: αρκεί η αντιγραφή.

**Το Chat Filter θα μπλοκάρει κατά λάθος κανονικές λέξεις;**
Ελέγχεται με δεκάδες χιλιάδες συνηθισμένες ελληνικές και αγγλικές λέξεις, ώστε οι κανονικές λέξεις (π.χ. *γάμος*, *Καλό γάμο!*, *μαλακό στρώμα*) να περνούν. Αν κάτι σταματήσει κατά λάθος, δοκιμάστε το στο **Try a message** και πείτε μας.

**Μετά από επανεκκίνηση, το chat δεν δέχεται μηνύματα για λίγα δευτερόλεπτα. Γιατί;**
Μέχρι να ξεκινήσει το Chat Filter (2–3 δευτερόλεπτα), το chat ζητά από τους χρήστες να ξαναδοκιμάσουν, ώστε να μη περάσει κανένα μήνυμα χωρίς έλεγχο.

**Πού αποθηκεύονται τα δεδομένα;**
Στον φάκελο `plugins_configs` του FM-DX σας: `stationlog.json`, `insights.json`, `fairshare.json`, `chatfilter.json` (και `chatfilter-log.json`, τα μηνύματα που σταμάτησαν), `antennaadvisor.json` και `dxwatch.json`.

**Σύνοψη στο Telegram;**
Βάλτε ένα αρχείο `.fmdx-telegram` στον φάκελο του χρήστη που τρέχει το FM-DX:
```
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=123456789
```
Το Listener Insights στέλνει τότε μια σύντομη σύνοψη κάθε Δευτέρα στις 09:00.
